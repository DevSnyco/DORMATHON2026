## SSH key auto-sync on CLI/MCP login (extension)
- New `POST /api/ssh-keys/self` (server/index.js): finds/creates a member by the login email, registers the local public key for every project that user is scoped to, then re-syncs affected in-scope servers (via syncServer). Computes OpenSSH `SHA256:` fingerprint (fingerprintOfPublicKey). Idempotent (skips existing publicKey+userId+projectId). Logs `sshkey.selfsync` to audit.
- Client (`client/irys-client.js`): `discoverSshKeys()` scans ~/.ssh (id_ed25519/ecdsa/rsa/dsa .pub; overrides via IRYS_SSH_DIR dir or IRYS_SSH_KEY file), `syncSelfSshKey(label)` posts each to /ssh-keys/self. `login()` auto-syncs unless disabled.
- CLI (`cli/irys.js`): login auto-runs `autoSyncKey()` (skippable with `--no-sync-key`); new `sync-key [--label L]` command; help documents both + the auto-sync behaviour.
- MCP (`mcp/irys-mcp.js`): new tool `irys_sync_my_ssh_key {label?}` (10 tools total now).
